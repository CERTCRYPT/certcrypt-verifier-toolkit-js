# Working in this repository

This repository is public. Keep every contribution self-contained and suitable
for public distribution.

- Write for readers who have this repository and the public sources it links to.
- Describe what the code does and why. Leave change history to version control.
- Include only information needed to understand, use, or evaluate this code.
- Do not add secrets, personal data, environment-specific values, or
  unpublished material.
- Write commit messages in English.
- Run the repository checks before committing. Do not bypass them; report a
  false positive instead.
